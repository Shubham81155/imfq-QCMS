🔒 Key is SHA-256 hashed. Never expose raw key in logs.

201 Created — Idea Imported Successfully

{"message": "Idea already imported."}
401 Unauthorized — Invalid or disabled API Key
{"error": "Unauthorized", "message": "Invalid or disabled API Key."}
429 Too Many Requests — Rate limit exceeded
{"error": "Too Many Requests", "message": "Rate limit exceeded."}
400 Bad Request — Missing required fields
{"success": false, "message": "Missing required fields: 'ideaCode' and 'title'."}

Field Type Required Description / Example
ideaCode string Required Unique ID from your Ideation Tool  "IDA-2026-006"

proposedSolution string Optional Suggested improvement or fix
department string Optional "Production", "Quality", "HR"

submittedBy string Optional Full name of the submitter  "John Doe"

investmentRequired number Optional Capital or operational cost in ₹  250000

impactLevel enum Optional "Low" / "Medium" / "High"
status string Optional Default: "Approved"
